MOUNTAIN TYCOON PWA + SUPABASE SETUP
====================================

REQUIRED FILES
--------------
- index.html
- manifest.webmanifest
- service-worker.js
- supabase-config.js
- supabase-schema.sql
- audio/
- icons/

SUPABASE
--------
1. Create or open the Supabase project.
2. Open SQL Editor and run the complete supabase-schema.sql file.
3. Under Authentication > Providers > Email, enable Email.
4. Turn Confirm email OFF because username accounts use internal email
   addresses that cannot receive confirmation messages.
5. Copy the Project URL and publishable key into supabase-config.js.
6. Never place a service_role key in browser files.

PRIVATE SAVES
-------------
- One player_saves row belongs to each authenticated account.
- save_data contains the complete three-world collection.
- Row Level Security prevents access to another player's collection.
- Old single-world saves remain loadable and migrate into slot 1.
- The public leaderboard exposes only username and lifetime money.

DEPLOYMENT
----------
1. Upload this entire folder without changing its internal paths.
2. Serve it over HTTPS; service workers do not run from file://.
3. Make index.html the root page.
4. Deploy service-worker.js whenever CACHE_NAME changes.
5. Fully reopen an installed copy or hard-refresh after an update.

OFFLINE
-------
The app shell and local world slots work offline after one successful online
load. Login, cloud synchronization, and leaderboard updates require internet.

INSTALLATION
------------
- Android Chrome: Install app or Add to Home screen.
- iPhone/iPad Safari: Share > Add to Home Screen.
- Desktop Chrome or Edge: use the install icon or browser menu.
