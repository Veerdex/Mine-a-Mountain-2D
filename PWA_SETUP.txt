MOUNTAIN TYCOON PWA + LEADERBOARD PACKAGE

FILES
- index.html
- manifest.webmanifest
- service-worker.js
- supabase-config.js
- supabase-schema.sql
- icons/

SUPABASE SETUP
1. Create or open your Supabase project.
2. Open SQL Editor, paste the complete supabase-schema.sql file, and run it.
   It creates both the private player_saves table and public leaderboard table.
3. Under Authentication -> Providers -> Email, enable Email.
4. Because the game uses username-based internal emails, turn Confirm email OFF.
5. Copy your Project URL and publishable/anon key into supabase-config.js.
6. Never place the service_role key in browser files.

DEPLOYMENT
1. Upload the entire folder together and preserve all filenames.
2. Serve it over HTTPS. PWAs/service workers do not work from file://.
3. Make index.html the root page.
4. When deploying later updates, increment CACHE_NAME in service-worker.js.

LEADERBOARD
- Rankings use lifetime money collected from item sales, not current cash.
- Only username and lifetime total are publicly readable.
- Full save data stays private under player_saves RLS.
- A database trigger prevents older saves from reducing a lifetime total.
- Older pre-leaderboard saves use current cash as the minimum recoverable total.

INSTALLING
- Android Chrome: use Install app / Add to Home screen.
- iPhone/iPad Safari: Share -> Add to Home Screen.
- Windows/macOS Chrome or Edge: use the address-bar install icon or browser menu.

OFFLINE
- The app shell and local save work offline after the first successful load.
- Login, cloud saves, and leaderboard updates require internet.
